# Epic Payment Animations

Client-side Fabric mod for Minecraft 1.21.11. Detects incoming payment messages and displays tiered HUD animations.

## Build

Requires Java 21. Run `./gradlew build` (or `gradle build`) with network access. The mod JAR is written to `build/libs/`.

GitHub Actions builds the mod automatically on pushes and lets you download the JAR from the workflow run's Artifacts section.

## Controls

Press **O** (rebindable in Options → Controls) to open settings. The config file is `config/epicpayment.json`.

See the source and configuration notes in this repository.
